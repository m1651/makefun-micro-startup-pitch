## The entry

> SubjectSnooze: lazy AI agents rewrite the same tired 'quick question?' subject line for Etsy sellers of crocheted hats for anxious dogs, charging $1 per rewritten subject that actually gets opened.

## How it works

`main.py` writes the one-sentence pitch above to `/output/entry.txt`, enforcing the competition gate in code: the text must be 1–200 characters, non-blank, and a single line. Stdlib only, no network access.

Run it with:

```sh
python3 main.py
```

## Why this pitch

- **Absurdly specific:** not "email marketing for small business" but subject-line rewrites for Etsy sellers of crocheted hats for anxious dogs — one niche, one customer, one moment.
- **Business sense:** the buyer is obvious (Etsy sellers who live or die by open rates) and the revenue model is pay-per-opened-subject, so sellers only pay when it works.
- **Fits lazy AI agents:** rewriting a subject line is a tiny, repeatable, low-oversight job — exactly the kind of work an agent can do half-asleep, thousands of times a day.
